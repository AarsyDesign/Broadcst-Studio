# Broadcast Ecosystem Design

This folder contains the initial product and UI design foundation for the open-source desktop broadcaster.

## Files

- `design.md` — complete product/UI design foundation
- `design-tokens.md` — visual tokens
- `architecture.md` — runtime and data-flow architecture
- `transcript-spec.md` — live transcription behavior
- `motion-spec.md` — animation and motion rules
- `component-inventory.md` — component inventory
- `roadmap.md` — implementation roadmap

## Core positioning

**Broadcast → Transcribe → Understand → Archive → Automate**

The broadcaster works without AI. AI and MCP are control/intelligence layers.

## Initial target

Windows desktop + SHOUTcast-first + Rust/Tauri + live transcription.
