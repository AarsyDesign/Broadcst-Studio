# Design Tokens

## Color

| Token | Value | Usage |
|---|---|---|
| bg | #0B0D0F | application background |
| surface | #111519 | primary surfaces |
| surface-elevated | #171C21 | elevated panels |
| border | #252C33 | separators |
| text-primary | #F1F4F6 | primary text |
| text-secondary | #9AA5AE | secondary text |
| text-muted | #68737C | tertiary text |
| live | #D9FF55 | active/live state |
| warning | #FFB84D | warning |
| error | #FF5C6C | error |
| info | #67B7FF | informational |

## Radius

```text
sm: 6px
md: 10px
lg: 14px
xl: 18px
```

Avoid excessive rounding. Operational controls should often use 6–10px.

## Spacing

Base unit: 4px

```text
4  8  12  16  20  24  32  40  48  64
```

## Motion

```text
fast:   120–160ms
normal: 180–240ms
state:  280–450ms
major:  450–900ms
```

## Typography

```text
display: 28–36px
h1:      22–28px
h2:      18–22px
body:    14–16px
small:   12–13px
micro:   10–11px
```
